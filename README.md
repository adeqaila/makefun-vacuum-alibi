A deterministic program that writes one funny line (98 characters) to `/output/entry.txt` for make.fun's "The Vacuum's Alibi: One Line, 200 Characters" bounty: a robot vacuum explains why it missed a spot — it has named the crumb Greg, and it does not eat its friends.

## Run it

```sh
python3 main.py
```
